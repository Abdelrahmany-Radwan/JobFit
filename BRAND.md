# JobFit Brand System

JobFit's visual system is designed to feel editorial, student-centered, and evidence-driven rather than like a generic AI product.

## Palette

| Role | Color |
| --- | --- |
| Canvas | `#FAF8F3` |
| Deep navy | `#203F5E` |
| Teal | `#288F98` |
| Soft teal | `#72B1AB` |
| Pink | `#DC5084` |
| Soft pink | `#F0ADC2` |
| Pale blush | `#EEE0E0` |

The interface uses navy for structure, teal for evidence and interaction, pink for human annotation, and pale blush for editorial surfaces.

## Typography

- **IBM Plex Sans** — interface, labels, body text, controls
- **Fraunces** — editorial headlines, emphasis, key numbers

The serif is intentionally limited to expressive moments; functional UI stays sans-serif.

## Visual language

JobFit treats evidence as a physical object:

- resume sheets
- highlighted source lines
- job-post scraps
- connection paths
- handwritten annotations
- receipts / proof

The goal is to make the product's core principle visible: **show the evidence before asking the user to trust the score.**

## Motion

Motion should explain relationships, not decorate the page.

- evidence paths animate only when demonstrating a match
- marquees pause on hover
- reduced-motion preferences are respected
- hover/focus states should reveal structure, not create distraction

## Voice

Short, direct, student-centered, and specific.

Prefer:
- "show me the receipt"
- "this counts"
- "same work. different words."

Avoid:
- generic "AI-powered" claims
- corporate buzzwords
- inflated hiring/ATS language
