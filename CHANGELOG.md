# Changelog

All notable released changes to JobFit are documented here.

## [1.0.0] - 2026-10-05

First stable release.

### Product
- Evidence-first requirement-to-resume matching
- Client-side PDF, DOCX, TXT, and pasted-text processing
- One-click sample experience
- Resume health checks
- Exact keyword coverage
- Prioritized action queue
- Interactive resume-to-requirement evidence map
- Company-example marquee and FAQ

### ML / retrieval
- MiniLM sentence embeddings in browser
- Hybrid semantic + lexical ranking
- Lexical fallback when semantic model loading fails
- 48-pair dev/test regression benchmark with hard negatives
- Precision, recall, F1, accuracy, and latency reporting

### Engineering
- GitHub Actions CI
- Unit tests for deterministic baseline
- Separate model-evaluation workflow
- GitHub Pages deployment
- Protected main-branch workflow
- Dependabot
- Architecture, contribution, brand, and security documentation
