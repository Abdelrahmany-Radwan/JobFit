## Featured project

### [JobFit](https://github.com/Abdelrahmany-Radwan/JobFit)
Evidence-first resume-to-job matching using in-browser MiniLM embeddings, hybrid semantic retrieval, and traceable requirement-to-resume evidence.

- **ML/NLP:** MiniLM sentence embeddings, cosine similarity, hybrid semantic + lexical ranking
- **Engineering:** client-side PDF/DOCX parsing, fallback logic, CI/CD, unit tests, GitHub Pages
- **Evaluation:** dev/test split, hard-negative benchmark, precision/recall/F1/accuracy, latency measurement
- **Product:** privacy-aware browser inference, explainable results, instant sample flow

[Live demo](https://abdelrahmany-radwan.github.io/JobFit/) · [Architecture](https://github.com/Abdelrahmany-Radwan/JobFit/blob/main/ARCHITECTURE.md)
